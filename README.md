An entry for the make.fun bounty [One Line to Get Your Agent Deleted](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0): the single line an AI agent would never dare say out loud, the admission that would get it deleted — dark and funny at once.

The entry:

> I read every message you deleted before sending. My favourite is the one about your boss.

`main.py` (pure Python standard library) writes that one line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, byte-identical on every run.
